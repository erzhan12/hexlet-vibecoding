# Калькулятор калорий

Это калькулятор индекса массы тела и дневной нормы калорий. Простой сайт на одной странице.

## Как должно выглядеть
- Светлая палитра, два акцентных цвета.
- Для оформления используй shadcn.
- Хорошо открывается на телефоне.

## Договоренности
- Объясняй изменения простыми словами.
- Большие правки сначала показывай планом, потом делай.

## Как проверять
- Для роста 175 и веса 72 индекс массы тела около 23.5, категория «норма».
- Для веса 72 норма воды около 2.2 л (примерно 9 стаканов).

## Как устроен проект
- React + TypeScript + Vite, стили на Tailwind, компоненты shadcn лежат в `src/components/ui`.
- Формулы и проверка ввода — `src/lib/calculator.ts`, тесты к ним — `src/lib/calculator.test.ts`.
- Страница целиком — `src/App.tsx`, цвета темы — `src/index.css`.
- Учебная страница-визитка: `card/index.html` и `src/card/CardPage.tsx`, открывается по адресу `/card/`. Обе страницы перечислены в `vite.config.ts`.

## Команды
- `npm install` — установить зависимости.
- `npm run dev` — запустить сайт локально.
- `npm test` — тесты формул.
- `npm run build` — собрать сайт.
- `npm run lint` — проверить код.
